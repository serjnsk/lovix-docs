# Админка — модуль «Управление контентом»

Цель: контент-менеджеры управляют каталогом сами — боты, категории, фото, промпты генерации — без разработчиков и без обходных путей через «Создать из фото». Раздел строится от двух интентов и двух табов: **«Категории»** (управляю витринами) и **«Шаблоны»** (управляю ботами). SEO выносится отдельно со своими правами: страницы и мета — у SEO, наполнение — у контента.

**[Живое демо функционала →](admin-demo.html)** — оба таба можно потрогать: галочки, pin, drag-n-drop, тулбар, диагностика характеристик. Там же — детальный список работ и критерии приёмки.

**Перенос из «Страниц»:** текущий функционал «Страницы → Категория» (вкладки Фильтр и Предпросмотр, генерационный тулбар) переезжает в меню **Админка → Управление контентом**. В «Страницах» остаётся SEO-часть: мета, тексты, индексация.

## Схема модуля

Ключевое изменение — **pin/exclude поверх автофильтра**: автофильтр остаётся базой (боты пользователей попадают в категории сами), ручное прикрепление и исключение работают поверх и переживают изменение фильтров.

## Проблемы, которые закрываем

| № | Боль из треда | Решение в модуле |
|---|---|---|
| Б1 | Нельзя руками добавить бота в категорию — только подгоном характеристик | Pin/exclude поверх автофильтра: галочки из базы и drag-n-drop (Р1) |
| Б2 | Характеристики ставит ИИ и они «надуманные»: однотипные лица, неверные категории | Ручная правка характеристик — источник правды, ИИ не перетирает (Р2) |
| Б3 | Непонятно, какие характеристики тянутся в какую категорию и кто задал фильтр | Фильтр читается прямо в таблице категорий + отчёт (Р1, Р5) |
| Б4 | Один и тот же генератор (Grok) даёт однообразный контент | Кастомный промпт изображений и выбор модели per категория (Р1) |
| Б5 | Одна фотка на все категории — приходится генерить дубли ботов и превью-видео | Метки фото per категория (Р3); превью не перегенерируются |
| Б6 | SEO и контент смешаны: фильтры делает SEO, наполняет КМ, ответственность размыта | Контент — новый раздел, SEO остаётся в «Страницах», права по ролям (Р4) |
| Б7 | Малочисленные категории ищутся вручную | Наполненность и порог прямо в таблице категорий + отчёт (Р1, Р5) |

## Р1. Таб «Категории»

| № | Требование |
|---|---|
| КТ1 | Таблица категорий: название, **слаг**, **локали ru/en/de** (отсутствующие страницы приглушены), фильтр в читаемом виде («характеристика — значение»), счётчик ботов (всего / по фильтру / pin), наполненность с настраиваемым порогом и подсветкой «мало» |
| КТ2 | Панель категории: выдача с бейджем источника (фильтр/pin), кнопка «Добавить из базы» — модалка со всеми ботами, поиском и галочками; уже входящие залочены (сценарий Насти: наполнить категорию за один проход) |
| КТ3 | Pin переживает изменение фильтра; exclude сильнее фильтра; списки «Прикреплённые» и «Исключённые» с возвратом |
| КТ4 | Помощник «поместить через характеристики»: проставляет минимальный набор характеристик под фильтр (когда pin нежелателен); при коллизии условий — предупреждение |
| КТ5 | Промпт генерации per категория: кастомный промпт изображений с переменными, выбор модели (Grok / Nano Banana / …), тестовая генерация 1 шт. до пачки |
| КТ6 | Промпты имён и описаний per категория с фолбэком на глобальный |
| КТ7 | Предпросмотр изменения фильтра: «кто войдёт / кто выпадет» до сохранения |
| КТ8 | Тулбар массовых операций по выбранным чекбоксами (перенос из «Страниц»): Обновить, Сгенерировать N, Создать из фото, Генерация превью, Догенерить галереи, Генерация сценариев, Тексты, Сохранить, Откатить. Без выбора — по всем с подтверждением. «Открыть/Закрыть от индекса» здесь нет — только в SEO |
| КТ9 | Drag-n-drop бота на категорию в доке — эквивалент pin; pointer events, работает мышью и тачем, клик не считается драгом |
| КТ10 | Ручной порядок выдачи поверх автосортировки: перетаскивание карточек в сетке; новые боты в конец; «Сбросить к автосортировке» |
| КТ11 | «Создать из фото»: загрузка/URL, имя, опция «сразу прикрепить (pin)»; новый бот помечается бейджем «новый». «Генерация превью» пропускает ботов с готовым превью |

## Р2. Таб «Шаблоны»

| № | Требование |
|---|---|
| К1 | Список всех шаблонных ботов: портрет, ключевые характеристики, колонка «в N категориях», поиск и фильтры |
| К2 | Карточка бота: все характеристики редактируются вручную; ручное значение помечается («вручную» с замком) и **не перетирается** переобработкой ИИ; бейдж «ИИ»/«вручную» у каждого поля |
| К3 | Блок «Категории бота» с чекбоксами: один бот прикрепляется сразу к нескольким категориям (milf + secretary + latina); по каждой видно происхождение (по фильтру — замочек, pin — галочка) и разбор условий фильтра с текущими значениями («возраст 40+: ✗, сейчас 34») |
| К4 | Массовые операции по выборке: проставить характеристику, прикрепить к категории, перегенерация описания |
| К5 | Переработка ИИ запускается вручную по кнопке (бот/выборка), не молча по всему каталогу |

## Р3. Медиатека

| № | Требование |
|---|---|
| М1 | У бота несколько фото; на фото — метки категорий (одна метка может покрывать несколько категорий) |
| М2 | В выдаче категории бот показывается с фото, помеченным этой категорией; нет метки — основное фото |
| М3 | Фото добавляются вручную и генерацией по промпту категории; превью-видео не перегенерируется, если уже есть |
| М4 | Основное фото назначается явно |

## Р4. SEO — остаётся в «Страницах»

| № | Требование |
|---|---|
| С1 | SEO-страница категории: slug, title, description, H1, тексты, hreflang/canonical — редактирует только роль SEO |
| С2 | Создание категории — из SEO-раздела: страница + черновик фильтра; дальше категория переходит контенту |
| С3 | Статусы категории: «черновик SEO» → «наполнение» → «опубликована»; неопубликованные не видны на сайте |
| С4 | Права: SEO не редактирует ботов и привязки; КМ не редактирует мету и slug; админ — всё |
| С5 | Управление индексацией (Открыть/Закрыть от индекса) — только здесь; из контентного тулбара кнопки убраны |

## Р5. Отчёты и аудит

| № | Требование |
|---|---|
| О1 | Отчёт «Категории»: фильтр в читаемом виде, счётчики всего/фильтр/pin, дата последнего изменения |
| О2 | Отчёт «Малочисленные»: ниже порога, сортировка по трафику страницы |
| О3 | Аудит-лог: кто и когда менял фильтр, характеристики, привязки, порядок, промпты — с прежним значением |

## Сценарии работы

| Сценарий | Шаги |
|---|---|
| Наполнить малочисленную категорию | Таблица категорий (подсветка «мало») → «Добавить из базы» → отметил галочками → pin; или перетащил карточки на категорию в доке. Без генерации дублей и новых превью |
| Один бот в несколько категорий | Таб «Шаблоны» → карточка → отметил категории чекбоксами; куда не проходит по фильтру — pin, куда проходит — по фильтру |
| Новая SEO-категория | SEO создаёт страницу и черновик фильтра → «наполнение» → КМ правит фильтр по предпросмотру, пинит, генерит пачку по промпту категории → «опубликована» |
| Пак новых ботов под категорию | Тест-генерация 1 шт. → правка промпта → пачка → авто-характеристики ИИ → выборочная ручная проверка → в категории по фильтру |

## Критерии приёмки

- Раздел открывается из меню Админки; в «Страницах» вкладок контента больше нет, старые ссылки ведут в новый раздел.
- В таблице категорий видны слаг и локали; счётчики совпадают с фактической выдачей на сайте.
- Бот, добавленный галочками, появляется в категории на сайте с источником «pin».
- Pin переживает изменение фильтра категории; exclude скрывает бота, даже если он проходит фильтр; возврат из исключённых работает.
- Перетаскивание на категорию ставит pin; внутри сетки — меняет порядок на сайте; сброс возвращает автосортировку.
- Драг работает мышью и тачем; обычный клик по карточке драгом не считается.
- Массовые операции применяются только к выбранным; без выбора — ко всем после подтверждения; каждая пишет запись в аудит-лог.
- «Создать из фото» создаёт шаблон и при включённой опции сразу пинит его в текущую категорию.
- «Генерация превью» запускается по выбранным и пропускает ботов с готовым превью.
- Характеристика, изменённая вручную, не меняется при массовой переобработке ИИ.
- Один бот одновременно виден в нескольких категориях (milf + secretary + latina), в карточке виден источник по каждой.
- Боты пользователей продолжают попадать в категории по автофильтру без ручных действий.
- Контентная роль не видит мету и индексацию; SEO-роль не редактирует ботов и привязки.

## Принятые решения

- Раздел строится от **двух интентов** — табы «Категории» и «Шаблоны» на одном состоянии; название — «Управление контентом».
- Автофильтр **остаётся базой** привязки — боты пользователей попадают в категории без ручного протыкивания (позиция Александра). Pin/exclude — поверх, не вместо.
- Ручные значения характеристик сильнее ИИ и не перетираются.
- Тулбар генерации переезжает из «Страниц» в контентный раздел; индексация остаётся в SEO.
- Промпты генерации управляются на уровне категории с фолбэком на глобальные.
- SEO и контент — разные разделы и разные права; категория проходит статусы от черновика SEO до публикации.

## Открытые вопросы

- Формат переменных в промптах категории — согласовать при Э2-1.
- Порог «малочисленности» по умолчанию — предложение: 12 ботов.
- Нужна ли модерация pin'ов (просмотр админом) или доверяем КМ полностью.
