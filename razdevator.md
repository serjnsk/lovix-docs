# Razdevator.hot — флоу продукта

Спека основного флоу **razdevator.hot**: генерация фото и видео по темплейтам из загруженного фото пользователя, монетизация токенами. Дизайн-система интерфейса: [Раздеватор · UI-кит](razdevator-ui.html). Здесь — путь от лендинга до результата и структура сайдбара; номиналы (цена генерации в токенах, размер стартового набора) задаются токеномикой продукта отдельно и в этой спеке не фиксируются.

## Архитектура

| ID | Требование |
|---|---|
| Т1 | Лендинг — **SSR** (ради индексации поисковиками), всё остальное — **SPA**. |
| Т2 | SPA ультраудобна и на мобильной версии, и на десктопе: одна кодовая база, адаптивная вёрстка, без урезания функций на мобиле. |

## Основной флоу

| ID | Шаг | Правило |
|---|---|---|
| Ф1 | Лендинг | Пользователь загружает фото и выбирает параметры генерации **до** регистрации. Второй вход — кнопка **«Войти»**: существующий пользователь попадает сразу в SPA (раздел «Фото») без загрузки фото. |
| Ф2 | Регвол | Показывается после загрузки и выбора параметров. Способы входа: **email + пароль и Google** (и на регволе, и на «Войти»). Фото и параметры при регистрации не теряются. Новому пользователю начисляются **стартовые токены** — первая генерация без оплаты. |
| Ф3 | Проверка баланса | Токенов хватает → генерация запускается сразу. Не хватает → пейвол. |
| Ф4 | Пейвол | Экран пополнения баланса токенов. После оплаты генерация стартует с сохранёнными фото и параметрами — повторная загрузка не нужна. |
| Ф5 | Генерация | Отдельная страница: исходное фото под блюром, поверх — лоадер. Параллельных генераций может быть **сколько угодно** — лимита нет, все крутятся в истории. |
| Ф6 | История | Готовое фото отображается полностью. Ещё генерящееся — с блюром. О готовности пользователь узнаёт **только здесь** — писем и пушей о готовности нет. |
| Ф7 | Просмотр объекта | Клик по готовому объекту в истории открывает модалку. В модалке три действия: **«Сгенерировать ещё раз»** (повтор с теми же фото и темплейтом), **«Сгенерировать другое»** (это фото — к выбору другого темплейта), **«Удалить»** (убрать объект из истории, с подтверждением). |
| Ф8 | Фейл генерации | Токены **автоматически возвращаются**, в истории вместо результата плашка «не получилось». Кнопку «попробовать ещё раз» **не показываем** — фото могло нарушать правила. |

## Запуск из каталога

| ID | Правило |
|---|---|
| К1 | Клик по **любому** шаблону в каталоге (Фото или Видео) открывает модалку шаблона: слева фото-пример в драг-н-дроп зоне, стрелка, справа конечная генерация этого примера. Своё фото пользователь кидает в тот же драг-н-дроп — пример замещается. |
| К2 | Кнопка запуска — **«Сгенерировать · N токенов»**: цена генерации показана прямо на кнопке (номинал — из токеномики продукта). |
| К3 | После нажатия модалка **не закрывается, пока сервер не подтвердил старт генерации**: крестик, Esc и клик по оверлею заблокированы на время запуска. |
| К4 | Старт подтверждён → модалка закрывается, показывается **тост «Генерация началась»**, объект появляется в истории с блюром. Пользователь остаётся в каталоге и может запускать следующую. |

Сознательно не зафиксировано (решим позже): модерация загружаемых фото, срок хранения истории и скачивание, дожим-письма по брошенному флоу.

## Сайдбар

| ID | Раздел | Содержимое |
|---|---|---|
| С1 | Фото | Каталог темплейтов генерации фото. Сверху — драг-н-дроп форма загрузки с **4 самыми сильными темплейтами**, ниже после разделителя — все темплейты тумбами. |
| С2 | Видео | Каталог темплейтов генерации видео, та же структура: драг-н-дроп форма с топ-4 темплейтами, после разделителя — все темплейты тумбами. |
| С3 | Баланс токенов | Текущий остаток + кнопка «Пополнить» (ведёт на пейвол). |
| С4 | Профиль | «Выйти» и «Удалить аккаунт». |

## Лендинг: правки к готовому дизайну

Дизайн лендинга готов; по мобильной версии две правки:

| ID | Правка |
|---|---|
| Л1 | Текст под H1 убрать под спойлер (свёрнут по умолчанию, раскрывается тапом). |
| Л2 | Драг-н-дроп форму поднять выше по странице. |

## Критерии приёмки

- Лендинг отдаётся SSR (контент виден в исходнике страницы без JS); после входа в продукт навигация работает как SPA, без полных перезагрузок.
- Кнопка «Войти» на лендинге: существующий пользователь попадает в SPA без загрузки фото.
- SPA полнофункциональна на мобиле и десктопе: без горизонтального скролла, все действия доступны с телефона.
- Незалогиненный на лендинге загружает фото и выбирает параметры — регвол появляется только после этого; после регистрации фото и параметры на месте.
- Новый пользователь после регвола получает стартовые токены, генерация запускается сразу, пейвола нет.
- Пользователь без токенов после регвола видит пейвол; после пополнения генерация стартует без повторной загрузки фото.
- Во время генерации открыта отдельная страница: исходник под блюром + лоадер поверх.
- В истории готовое фото — без блюра; генерящееся — с блюром; после завершения блюр снимается без ручного обновления.
- В сайдбаре ровно четыре раздела: Фото, Видео, Баланс токенов, Профиль.
- «Фото»: сверху драг-н-дроп форма с 4 сильнейшими темплейтами, ниже разделитель и полный список темплейтов тумбами. «Видео» — та же структура.
- «Баланс токенов»: виден остаток, «Пополнить» открывает пейвол.
- «Профиль»: «Выйти» разлогинивает; «Удалить аккаунт» удаляет с подтверждением.
- Модалка объекта в истории: «Сгенерировать ещё раз» запускает повтор с теми же фото и темплейтом; «Сгенерировать другое» ведёт к выбору темплейта с этим фото; «Удалить» убирает объект после подтверждения.
- Мобильный лендинг: текст под H1 свёрнут в спойлер, драг-н-дроп форма поднята выше.
- Клик по шаблону в каталоге открывает модалку: пример «до→после» со стрелкой, своё фото кидается в тот же драг-н-дроп, на кнопке «Сгенерировать» видна цена в токенах.
- Во время запуска генерации модалку нельзя закрыть (крестик, Esc, клик мимо); после подтверждения старта она закрывается сама, показывается тост «Генерация началась».
- Регвол и «Войти» работают обоими способами: email + пароль и Google.
- Несколько генераций крутятся параллельно, каждая видна в истории с блюром.
- При фейле генерации токены возвращаются на баланс автоматически, в истории плашка «не получилось» без кнопки повтора.
