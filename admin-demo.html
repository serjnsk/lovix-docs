Админка · Управление контентом — демо

Два таба на одном состоянии: Категории — витрины, наполнение, порядок; Шаблоны — боты, характеристики, привязка одного бота в несколько категорий. Всё в демо кликается и таскается.

Живое демо

UI — светлая тема текущей админки. Категории: открой «Горничные», добавь ботов галочками; карточку можно перетащить — в док справа (pin) или внутри сетки (ручной порядок). Чекбоксы + «Генерация превью» — прогресс на карточках. Шаблоны: Мария — milf галочкой или возраст 42, категория загорится «по фильтру».

Что нужно сделать

Скоуп раздела «Управление контентом» для нарезки. Детальные требования и декомпозиция по этапам — в спеке.

1Перенос раздела

  • Вынести из «Страницы → Категория» в меню Админка → «Управление контентом»
  • В «Страницах» остаются только SEO: мета, тексты, индексация
  • Старые ссылки ведут в новый раздел

2Таб «Категории»

  • Таблица: название, слаг, локали (ru/en/de, отсутствующие приглушены), фильтр в читаемом виде, счётчик всего/по фильтру/pin, наполненность с настраиваемым порогом и подсветкой «мало»
  • Панель категории: выдача с бейджем источника (фильтр/pin), «Добавить из базы» — модалка с поиском и чекбоксами, уже входящие залочены
  • Исключение бота из категории и возврат из списка исключённых

3Pin / exclude

  • Pin поверх автофильтра: бот в категории независимо от характеристик, переживает изменение фильтра
  • Exclude сильнее фильтра; источник попадания хранится и показывается
  • Автофильтр не отключается — боты пользователей продолжают попадать сами

4Drag-n-drop

  • Карточку на категорию в доке — pin (счётчики обновляются сразу)
  • Внутри сетки — ручной порядок выдачи поверх автосортировки; новые в конец; «Сбросить к автосортировке»
  • Pointer events: мышь и тач; порог, чтобы клик не считался драгом

5Тулбар операций

  • Обновить · Сгенерировать N · Создать из фото · Генерация превью · Догенерить галереи · Генерация сценариев · Тексты · Сохранить · Откатить
  • Работают по выбранным чекбоксами; без выбора — по всем с подтверждением
  • «Создать из фото»: загрузка/URL, имя, опция «сразу прикрепить (pin)»
  • Превью не перегенерируется у тех, у кого уже есть
  • Индексация в тулбаре отсутствует — только в SEO-разделе

6Таб «Шаблоны»

  • Список ботов: портрет, характеристики, «в N категориях»
  • Карточка: правка характеристик, бейджи «ИИ»/«вручную», ручное не перетирается переобработкой
  • Чекбоксы категорий: один бот в несколько категорий сразу; по каждой видно происхождение и разбор условий фильтра с текущими значениями

Критерии приёмки

  • Раздел открывается из меню Админки; в «Страницах» вкладок контента больше нет
  • В таблице категорий видны слаг и локали; счётчики совпадают с фактической выдачей
  • Бот, добавленный галочками, появляется в категории на сайте с источником «pin»
  • Pin переживает изменение фильтра категории; exclude скрывает бота, даже если он проходит фильтр
  • Перетаскивание на категорию ставит pin; внутри сетки — меняет порядок на сайте; сброс возвращает автосортировку
  • Драг работает мышью и тачем; обычный клик по карточке драгом не считается
  • Массовые операции применяются только к выбранным; каждая пишет запись в аудит-лог
  • «Создать из фото» создаёт шаблон и при включённой опции сразу пинит его в текущую категорию
  • «Генерация превью» запускается по выбранным и пропускает ботов с готовым превью
  • Характеристика, изменённая вручную, не меняется при массовой переобработке ИИ
  • Один бот одновременно виден в нескольких категориях (milf + secretary + latina)
  • Боты пользователей продолжают попадать в категории по автофильтру без ручных действий
  • Контентная роль не видит мету и индексацию; SEO-роль не редактирует ботов и привязки

SEO — как есть

SEO-раздел не меняется: страницы, мета, тексты, индексация — как сейчас. «Управление контентом» работает поверх созданных категорий и SEO-часть не трогает.
