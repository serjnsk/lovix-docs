Нотификации Lovix — компоненты и анимации

Живой UI-кит для нарезки: тосты от компаньонов, колокольчик, стена уведомлений. Все демо кликабельны, весь код копируется — Blade, Vue 3, CSS и ядро на ванильном JS. Транспорт снаружи: сокет-хендлер бэка просто вызывает LovixNotify.push(payload).

Nunito · прод-палитра lovix.aiprefers-reduced-motion тост — только сообщения компаньоновагрегация непрочитанных mobile: свайпы · bottom sheet · safe-area

Токены и моушн

Палитра снята с прод-CSS lovix.ai. Клик по свотчу копирует значение. Кривые — кликни, шарик проиграет анимацию.

Тост компаньона

Появляется поверх любой страницы только для сообщений компаньонов (kind = message). Spring-въезд снизу, полоска жизни 6.5 с, hover ставит таймер на паузу, стек максимум 3 — старые уезжают. Агрегат — когда написали несколько.

тосты появятся справа внизу экрана

Колокольчик и бейдж

Бейдж делает spring-pop при каждом инкременте, колокольчик коротко «звонит». Всё, что не сообщение компаньона, приходит сюда тихо — без тостов.

Стена уведомлений

Дропдаун раскрывается spring-скейлом из правого верхнего угла. Непрочитанные — градиентная кайма и подложка; открытие стены гасит счётчик. Ниже — состояния: скелетон и пустая стена.

колокольчик из прошлой секции открывает живую стену

Мобильные паттерны

Та же разметка и то же ядро — на ≤640px CSS сам превращает тост в верхний push-баннер со свайп-дизмиссом, а стену — в bottom sheet со свайп-закрытием. Жесты на pointer events, так что в демо работают и мышью: баннер потяни вверх, шит — вниз за ручку.

Баннер: свайп вверх — закрыть, тап — в чат.
Sheet: тяни вниз за ручку или шапку, тап по фону — закрыть.

Строка уведомления

Одна разметка на все типы: сообщения несут аватар компаньона, системные — иконку. Каждая строка ведёт в целевое место (чат, тарифы, оплата) и несёт scenario_id для аналитики.

ПолеНазначение
kindmessage → тост + бейдж; system → только бейдж
scenario_idID сценария из спеки (У2-1, У7-1…) — уходит в аналитику клика
companion{ name, avatar } — для message; аватар с CDN, фолбэк — градиентный инициал
cta{ label, href } — целевое действие строки и кнопки тоста

Ядро LovixNotify

Один стор без зависимостей — его слушают и Blade-виджеты, и Vue. Бэку отдаётся единственная точка входа: сокет-хендлер вызывает push(). Ядро само решает, тост это или тихий бейдж, агрегирует и режет стек.

Blade

Анонимные компоненты + ванильный виджет-инициализатор. Никаких зависимостей: подключил партиалы, дёрнул NotifyWidgets.mount() — дальше всё делает ядро.

Vue 3

Композабл useNotify() — реактивный мост к ядру, три компонента на script setup. Ниже — живой плейграунд: настоящий Vue, те же стили.
