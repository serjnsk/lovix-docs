Автоопределение локали — живая спека

Весь трафик идёт через Cloudflare; решение о редиректе принимается на стороне CF до отдачи страницы. От CF берём гео по IP (ISO-код страны, свои списки IP не храним) и метку VPN. Алгоритм ниже — настоящая функция: её гоняет симулятор, её же прогоняют критерии приёмки, её исходник копируется разработчику.

Критерии приёмки — прогоняются по-настоящему

Каждая карточка вызывает ту же resolveLocale() и сверяет результат с ожиданием. Зелёный PASS честный, не нарисованный.

Партнёрка

  • Реф-метки (ref, UTM и прочие) сохраняются при редиректе на другую локаль
  • Переход по партнёрской ссылке с редиректом — атрибуция засчитывается
  • Параметры не теряются ни при автоопределении, ни при ручном переключении, ни при возврате после оплаты

SEO

  • Редирект не срабатывает для поисковых ботов — они получают запрошенную версию
  • Каноникалы и hreflang корректны на всех локалях
  • Sitemap открывается и валиден

Инфраструктура

  • Весь трафик через CF, включая РФ — без деградации для РФ-пользователей
  • Гео от CF в ISO-формате, собственные списки IP не используются
  • Метка VPN доступна и логируется для аналитики

А4Язык en / en-US неинформативен — решаем по гео из CF
А5VPN-кейс (гео ≠ язык, например IP 🇳🇱 + браузер RU) — приоритет за языком браузера
№Сохранение выбора
С1Авторизованный — локаль в профиле; при логине с любого устройства переключаем на неё
С2Неавторизованный — локаль в куке; кука переживает повторные визиты
