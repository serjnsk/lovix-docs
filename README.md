# Lovix — внутренняя документация

Сайт: **https://serjnsk.github.io/lovix-tokenomics/** — публикуется автоматически при push в `main` (GitHub Pages, задержка ~1 мин).

## Как устроен репозиторий

Здесь два типа страниц — правятся они по-разному.

### 1. Генерируемые страницы — руками НЕ править

| Страница | Источник контента |
|---|---|
| `index.html` (Токеномика) | `MODULE_1_tokenomics.md` |
| `metrics.html` (Метрики) | `MODULE_2_metrics.md` |
| `events.html` (События) | `MODULE_3_events.md` |
| `scenarios.html` (Сценарии) | `MODULE_4_scenarios.md` |

Эти четыре файла собираются скриптом `build.sh` из markdown-источников и шаблонов. **Прямая правка этих HTML будет молча стёрта следующей сборкой.** В каждом из них первая строка — предупреждение об этом.

Что где править:

- **Текст, таблицы, правила** → соответствующий `MODULE_*.md`
- **Оформление, навигация, скрипты** этих 4 страниц → шаблоны:
  - `_p0_head.html` … `_p4_tail.html` — страница «Токеномика» (в `_p0_head` живут прототипы тарифов и пакетов, в `_p4_tail` — их JS)
  - `_m_head.html` / `_e_head.html` / `_n_head.html` — шапки Метрик / Событий / Сценариев
  - `_m_foot.html` — общий низ трёх страниц: рендер markdown, чипы, оглавление-сайдбар

После любой правки — пересобрать:

```bash
bash build.sh
```

Скрипту нужны только `bash`, `awk`, `cat` — ничего ставить не надо.

### 2. Самостоятельные страницы — правятся напрямую

`trigger-system.html`, `trigger-marketing.html`, `email-template.html`, `email-builder.html`, `notifications-ui.html`, `emails/…` — обычные HTML, сборка их не трогает. Правь как хочешь.

**Добавил новую страницу** — добавь ссылку в навигацию во всех шаблонах шапок (`_p0_head.html` — там ссылки с inline-стилями, и `_m_head` / `_e_head` / `_n_head`) и запусти `bash build.sh`, иначе на четырёх генерируемых страницах ссылки не появится.

## Рабочий цикл

```bash
git pull                 # всегда перед началом работы
# ... правки ...
bash build.sh            # если трогал MODULE_*.md или шаблоны _*
git add -A && git commit -m "..."
git push
```

## Локальный просмотр

```bash
node serve.mjs
```

Откроется на `http://localhost:8899`.

## Терминология

Канонические имена событий (`payment.succeeded`, `quota.message_blocked`, …) — в `MODULE_3_events.md`, ID сценариев (У1-1 …) — в `MODULE_4_scenarios.md`. Контент-слой (тексты писем, спеки рассылок) ссылается на структуру по этим ID — при изменении структуры проверь свои страницы на битые ссылки.

## Правила и история

Правила оформления и структуры страниц — [DOCS_RULES.md](DOCS_RULES.md). История содержательных изменений доки — [CHANGELOG.md](CHANGELOG.md) (только в репозитории, на Pages не публикуется); каждое изменение — строка тем же коммитом.
