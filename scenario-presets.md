# Пресеты сценариев чата

Сценарий это готовая кнопка старта диалога в карточке бота: наименование и пояснение. Документ описывает сущность сценария, автоматический подбор сценариев под каждого бота, массовую генерацию и управление в админке.

Живьём: [демо раздела админки](scenario-presets-demo.html) · [демо создания сценариев](scenario-wizard-demo.html).

## Схема

Кликни и потаскай холст, колесо — зум.

## Сущность сценария

| ID | Правило |
|---|---|
| С1 | Сценарий состоит из наименования и пояснения и хранит переводы на ru, en, de. Пользователю показывается текст его локали. |
| С2 | Сценарий относится ровно к одному из трёх типов, тип определяет условия показа и слот: **категорийный** несёт условия по параметрам бота (пол, возраст, род занятий, этничность, стиль и прочие характеристики из общего словаря), **локальный** несёт список локалей (ru, en, de), **универсальный** условий не имеет и подходит любому боту. |
| С3 | Локали настраиваются только у локальных сценариев. Категорийные и универсальные показываются во всех локалях. |
| С4 | Условия по параметрам соединяются через **И**. Внутри одного параметра допустим список значений: «род занятий: секретарша или горничная». |
| С5 | Сценарий бывает в одном из двух форматов: **обычный** или **spicy**. Spicy показываются всем, использовать их может пользователь с активной подпиской. |
| С6 | **Даты активности с и по** ограничивают период показа. Вне периода сценарий в наборы не попадает. |
| С7 | Наименование и пояснение не редактируются. Неудачный сценарий выключают или удаляют, вместо него генерируют новый. |

## Подбор сценариев на бота

| ID | Правило |
|---|---|
| М1 | У бота 12 слотов: 6 обычных и 6 spicy. Внутри каждой шестёрки 2 категорийных слота, 2 локальных, 2 универсальных. |
| М2 | Кандидат проходит в слот своего типа: категорийный при совпадении всех условий с параметрами бота, локальный при совпадении локали пользователя, универсальный в универсальный слот. |
| М3 | Кандидатов больше, чем слотов: выигрывает сценарий с большим числом совпавших условий. |
| М4 | При равной точности выигрывает сценарий, закреплённый за **наименьшим числом ботов**. При равных счётчиках выбор случайный. Так новые сценарии расходятся по базе, а наборы разных ботов отличаются. |
| М5 | Один сценарий занимает у бота **не больше одного слота**. |
| М6 | Подходящих сценариев не хватило на слоты своего типа — fallback: слот заполняется **случайным универсальным**. У бота всегда 12 кнопок. |
| М7 | Наборы хранятся готовыми, карточка бота открывается без вычислений. |
| М8 | Наборы пересобираются **раз в неделю**, а также внепланово: при изменении параметров бота, при публикации или удалении сценариев, при наступлении или окончании дат активности. Между пересборками набор бота одинаков для всех пользователей независимо от аккаунта и времени захода. |

## Массовая генерация

| ID | Правило |
|---|---|
| В1 | Форма запуска: тип сценария, формат (обычные или spicy), условия показа, даты активности, дополнительный контекст, язык, количество. |
| В2 | Набор полей на шаге условий зависит от типа: у категорийного задаются параметры бота, у локального список локалей, у универсального условий нет. |
| В3 | Выбор категории подставляет её параметры в условия, дальше условия правятся и дополняются вручную. |
| В4 | У обычных и spicy сценариев **разные промпты генерации**. Промпты заданы в системе. |
| В5 | Генерация идёт фоном пачкой. По окончании доступен отчёт: создано, отброшено дублей. |
| В6 | Сценарий, близкий по смыслу к существующему в пуле, в черновики не попадает. |
| В7 | Сгенерированное попадает в черновики. В общий пул сценарий уходит после апрува, апрув возможен пачкой. |

## Раздел в админке

| ID | Правило |
|---|---|
| А1 | Список всех сценариев с фильтрами по типу, формату, локали, статусу и датам. Условия показа выводятся в читаемом виде. |
| А2 | Действия над сценарием: включить, выключить, удалить. |
| А3 | Массовые действия: чекбоксы в строках, выделение нескольких сценариев, выделение всего в пределах текущего фильтра. Над выбранными доступны включить, выключить и удалить одной кнопкой, рядом счётчик выбранных. |
| А4 | По каждому сценарию показы и клики за период. |
| А5 | Вкладка черновиков: апрув и удаление пачкой, подозрительные дубли помечены. |
| А6 | Вкладка **«Проверка на боте»**: выбранный бот показывает свои 12 слотов с пояснением, по какому условию туда попал каждый сценарий. Локаль пользователя переключается. |
| А7 | Вкладка **«Покрытие ботов»**: таблица всех ботов с их параметрами и категориями. По каждой локали видно, сколько сценариев подобралось боту, отдельно обычных и spicy. Боты, которым не хватило сценариев своего типа, помечены; фильтр показывает только их. Строка открывает разбор набора этого бота. |

## Миграция

Существующие сценарии переносятся в пул как универсальные. Дальше они отсеиваются по показам и кликам.

## Критерии приёмки

- У любого бота 12 кнопок: 6 обычных и 6 spicy, в каждой шестёрке 2 категорийных, 2 локальных, 2 универсальных.
- Бот «женщина, 42, секретарша» получает сценарии, подходящие этим параметрам, и не получает сценарии других типажей.
- Пользователь с локалью de видит локальные сценарии для de, категорийные и универсальные независимо от локали, тексты всех сценариев на немецком.
- В форме генерации у категорийного типа нет выбора локалей, у локального нет параметров бота.
- Два пользователя с разных аккаунтов видят у одного бота одинаковый набор; набор сохраняется до ближайшей пересборки.
- Пересборка проходит раз в неделю и дополнительно после изменения параметров бота, публикации или удаления сценариев.
- Новый сценарий после апрува попадает к ботам с наименьшими счётчиками привязок и расходится по базе.
- У бота нет двух одинаковых кнопок.
- Подходящих сценариев типа меньше двух: слоты добраны случайными универсальными, кнопок по-прежнему 12.
- Сценарий с датами активности не показывается до даты начала и пропадает после даты окончания.
- Выключенный или удалённый сценарий исчезает из наборов после пересборки, пустого места не остаётся.
- Пачка на 50 сценариев уходит в фон, по завершении доступен отчёт со счётчиком дублей, результат лежит в черновиках.
- Черновик до апрува не попадает ни в один набор.
- Генерация spicy использует отдельный промпт.
- В списке можно выделить несколько сценариев и одной кнопкой включить, выключить или удалить их; счётчик совпадает с числом отмеченных строк.
- Выделение всего отмечает только то, что показывает текущий фильтр.
- В списке видно показы и клики за выбранный период.
- В «Проверке на боте» для каждого из 12 слотов указано, по какому условию сценарий туда попал.
- В «Покрытии ботов» за один экран видно, каким ботам не хватает сценариев и по какой локали.
